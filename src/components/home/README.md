# Home page sections

Each homepage section has its own folder, and the Vue file uses the same name as the folder.

1. `HeroSection/HeroSection.vue` — main homepage hero and quick collection links
2. `AssuranceSection/AssuranceSection.vue` — delivery, care and quality assurances
3. `BrandMarqueeSection/BrandMarqueeSection.vue` — scrolling brand-value text strip
4. `CategoryCollectionSection/CategoryCollectionSection.vue` — necklaces, earrings, rings and bracelets category cards
5. `JewelleryShowcaseSection/JewelleryShowcaseSection.vue` — sticky full-screen collection showcase
6. `EditorialCampaignSection/EditorialCampaignSection.vue` — two-image editorial campaign section

8. `PearlOrbitSection/PearlOrbitSection.vue` — Orbit rings editorial feature

12. `MuseStorySection/MuseStorySection.vue` — Lunara muse editorial and video section
13. `OrganicPearlStorySection/OrganicPearlStorySection.vue` — organic/baroque pearl story
14. `BrandFilmSection/BrandFilmSection.vue` — full-width brand film section
15. `FeaturedProductsSection/FeaturedProductsSection.vue` — most-loved product grid
16. `PearlFinderSection/PearlFinderSection.vue` — interactive pearl recommendation section
17. `AtelierStorySection/AtelierStorySection.vue` — atelier introduction section
